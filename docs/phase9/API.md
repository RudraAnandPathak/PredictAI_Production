# Development Workspace API (`/api/v1/dev`, versioned with the rest of v1)
All routes need a session; changing routes need CSRF; all return `{data, meta}` or the standard error envelope. Base for project routes: `/dev/projects/{project_id}`.
`GET /dev/overview` (landing; locked state returns only `access`) · `/history`, `/timeline` · `/files` (GET tree), `/files/content` (GET, PUT), `/files/delete`, `/files/restore`, `/files/history`, `/files/search` · `/notebooks`, `/notebooks/info`, `/notebooks/export` · `/sessions`, `/sessions/{id}/touch|stop` · `/envs` (+ `/{id}`, `/requirements`, `/packages`, `/packages/remove`, `/rebuild`, `/compare`, `/delete`) · `/jobs` (+ `/{id}`, `/logs`, `/cancel`, `/retry`, `/artifacts`) · `/secrets` (+ `/{id}/revoke`; values never returned) · `/artifacts` (+ `/summary`, `/{id}`, `/delete`, `/retention`) · `/git` (+ `/init`, `/connect`, `/disconnect`, `/log`, `/branches`, `/tags`, `/diff`, `/commit`, `/branches/switch`, `/pull`, `/push`) · `/pipelines`, `/pipeline-runs` (+ `/cancel`, `/approve`, `/reject`, `/deploy` -> 501) · `/experiments` (+ `/compare`, `/{id}`, `/run`, `/link-model`, `/approve`, `/revoke-approval`, `/rollback-target`, `/lineage`) · `/compute/limits`, `/compute/usage` · `GET /dev/compute/capabilities` · Owner: `GET|PUT /dev/owner/compute-overrides`, `POST .../clear` · Webhook (no session/CSRF, signed): `POST /dev/webhooks/git/{repo_id}`.
Error codes used: `SPECIAL_ACCESS_REQUIRED` 403, `NOT_FOUND` 404, `VALIDATION_ERROR` 422, `CONFIRMATION_REQUIRED` 409, `STORAGE_QUOTA_EXCEEDED` 403, `FILE_TOO_LARGE` 403, `EXECUTION_DISABLED` 403, `SESSION_UNAVAILABLE` 409, `WORKSPACE_SUSPENDED` 409, `DEPLOY_DISABLED` 501, `SECRETS_UNAVAILABLE`.
